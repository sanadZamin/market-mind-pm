Market Mind PM API (0.1.0)

Download OpenAPI specification:

License: MIT

HTTP API for the Market Mind project management tool (Spring Boot and Node implementations share these route shapes).

Base path: All paths below are served under the servlet context /api (e.g. https://host/api/projects).

When the SPA is deployed under a subpath (e.g. /pm), the browser calls /pm/api/...; reverse proxies typically forward that to the backend /api/....

Authentication: Most routes require Authorization: Bearer <token> from POST /auth/login or POST /auth/register.

Not HTTP: A scheduled job sends a daily delayed tasks digest email (config: pm.delayed-task-digest.* / PM_DELAYED_TASK_DIGEST_*). There is no REST endpoint for that digest.

Health probes: Actuator routes are documented under paths (/actuator/health, /actuator/health/liveness). No Bearer token required.
